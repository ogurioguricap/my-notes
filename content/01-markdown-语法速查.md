## 标题与分级

`#` 到 `######` 六级标题。**本页右侧目录只收录二到四级**，所以正文里请用 `##` 起头，`#` 留给标题本身。

## 表格

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | :---: | --- |
| title | 文本 | 是 | 标题 |
| category | 文本 | 否 | 分类，默认取文件夹名 |
| tags | 列表 | 否 | 标签 |
| date | 日期 | 否 | 不写取文件修改时间 |

## 代码块

```python
import numpy as np

def stationary_matrix(n=3, seed=42):
    """构造一个随机矩阵并求平稳分布"""
    rng = np.random.default_rng(seed)
    P = rng.random((n, n))
    P = P / P.sum(axis=1, keepdims=True)      # 每行归一化
    w, v = np.linalg.eig(P.T)
    i = np.argmin(np.abs(w - 1.0))
    pi = np.real(v[:, i])
    return P, pi / pi.sum()

P, pi = stationary_matrix()
print("平稳分布:", np.round(pi, 4))
```

## 公式

行内公式用单个美元符号：总体期望 $\mathbb{E}[X]=\sum_{i} x_i p_i$ 可以直接嵌在句子里。

块级公式用两个美元符号独占一段：

$$
P(X_{n+1}=j \mid X_n=i,\; X_{n-1}=i_{n-1},\dots) = P_{ij}
$$

$$
\pi P = \pi,\qquad \sum_{j=1}^{N}\pi_j = 1
$$
