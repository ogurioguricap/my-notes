# 数模方法速查卡

拿到题先判类型，再选方法。**选错类型比选错模型致命得多。**

## 一眼定类型

| 题目关键词 | 类型 | 首选方法 | 备选 |
| --- | --- | --- | --- |
| 最小成本、最大化收益、排班、路径 | 优化 | 整数规划（MILP） | 遗传/模拟退火、贪心+局部搜索 |
| 预测未来、趋势、走势 | 预测 | ARIMA / 指数平滑 | LSTM、灰色 GM(1,1)、随机森林 |
| 排名、打分、优劣、综合 | 评价 | 熵权法 + TOPSIS | AHP、主成分分析、DEA |
| 机理、物理过程、传染、扩散 | 机理 | 微分方程组 | 元胞自动机、蒙特卡洛 |
| 关系、影响因素、相关性 | 统计 | 多元回归 | 岭回归/Lasso、结构方程 |
| 策略、博弈、多主体 | 决策 | 博弈论 / 多目标优化 | 强化学习、仿真 |

## 优化类：建模顺序

1. **决策变量**是什么（连续/整数/0-1）
2. **目标函数**（单目标先写清，多目标再加权或 ε-约束）
3. **约束**逐个列（容量、平衡、逻辑、非负）
4. 检查**规模**：变量数 > 10⁴ 就上启发式，否则精确解

```python
# 线性规划模板（scipy）
from scipy.optimize import linprog
c = [-3, -5]                      # 最大化 3x+5y → 取负
A = [[1, 0], [0, 2], [3, 2]]
b = [4, 12, 18]
res = linprog(c, A_ub=A, b_ub=b, bounds=[(0, None), (0, None)], method='highs')
print(res.fun * -1, res.x)
```

多目标别直接拍权重：先求 Pareto 前沿（ε-约束法），再说明折中依据。

## 预测类：数据先说话

> [!IMPORTANT] 先看数据，再选模型
> 少于 30 个点：指数平滑或灰色预测；
> 有明显季节：SARIMA 或 分解后建模；
> 有外部变量：回归类（含岭/Lasso）；
> 非线性强且样本多：机器学习模型 + 交叉验证。

评价指标统一用 **MAPE** 或 **RMSE**，并与「朴素法（上一期值）」对比——打不过朴素法就没必要上复杂模型。

## 评价类：三件套

1. 指标标准化（正向/负向/区间型处理）
2. 权重确定（熵权法客观 / AHP 主观，常用组合赋权）
3. 排序（TOPSIS 贴近度，或灰色关联度）

```python
import numpy as np
def entropy_weight(X):
    """X: n×m 正向化后的矩阵 → 客观权重"""
    P = X / X.sum(axis=0, keepdims=True)
    P = np.clip(P, 1e-12, None)
    e = -(P * np.log(P)).sum(axis=0) / np.log(len(X))
    g = 1 - e
    return g / g.sum()
```

## 检验与灵敏度（评委最爱看）

- 拟合优度 $R^2$、残差正态性、多重共线性（VIF）
- **灵敏度分析**：关键参数 ±10% 扫描，看结论是否翻转
- **稳健性**：换一组随机种子/换一种距离度量，排名是否一致

## 论文里必须出现的四句话

1. 为什么选这个模型（而不是隔壁那个）
2. 模型假设是什么（每条标注强弱）
3. 结果的具体数字（不是「显著提高」）
4. 结果的不确定性（区间、误差、灵敏度）
