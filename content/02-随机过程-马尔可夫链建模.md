# 随机过程 · 马尔可夫链建模笔记

这类题的共同骨架是：**把连续的现实切成有限个状态 → 估计一步转移概率 → 求长期分布 → 用长期分布回答决策问题**。下面按这四步记录。

## 第一步：状态划分

状态必须是「互斥且完备」的。划分太粗，转移概率失去意义；划分太细，样本量撑不起参数估计。

> [!IMPORTANT] 状态数经验值
> 一般取 **3～6 个状态**。样本量 $n$ 时，转移矩阵有 $k(k-1)$ 个自由参数，粗算每个参数至少要 10 条以上的转移记录才稳。

## 第二步：估计转移矩阵

设样本中从状态 $i$ 转移到状态 $j$ 的频数为 $n_{ij}$，则

$$
\hat{P}_{ij}=\frac{n_{ij}}{\sum_{j=1}^{k} n_{ij}},\qquad i,j=1,\dots,k
$$

若某些 $n_{ij}=0$ 会造成零概率陷阱，用拉普拉斯平滑（加一平滑）：

$$
\hat{P}_{ij}=\frac{n_{ij}+\alpha}{n_i + k\alpha},\qquad \alpha \in [0.1,\,1]
$$

```python
import numpy as np

def estimate_transition(seq, k, alpha=1.0):
    """seq: 状态序列（0..k-1）；返回加一平滑后的转移矩阵"""
    counts = np.zeros((k, k))
    for a, b in zip(seq[:-1], seq[1:]):
        counts[a, b] += 1
    return (counts + alpha) / (counts.sum(axis=1, keepdims=True) + k * alpha)

def stationary(P):
    """求平稳分布：解 pi P = pi, sum(pi)=1"""
    k = P.shape[0]
    A = np.vstack([P.T - np.eye(k), np.ones(k)])
    b = np.append(np.zeros(k), 1.0)
    pi, *_ = np.linalg.lstsq(A, b, rcond=None)   # 最小二乘更稳
    return pi / pi.sum()

rng = np.random.default_rng(42)
P = estimate_transition(rng.integers(0, 3, size=2000), k=3)
print("平稳分布 π =", np.round(stationary(P), 4))
```

## 第三步：长期行为

若链不可约且非周期，则 $\pi = \lim_{n\to\infty} \pi^{(n)}$，与初始分布无关。验证收敛可以画幂次迭代曲线：

$$
\pi^{(n+1)} = \pi^{(n)} P
$$

![模型收敛示意图（演示图片文字检索）](assets/demo-convergence.png)

> [!WARNING] 常见失分点
> 直接说「所以最终会收敛到平稳分布」而不验证**不可约 + 非周期**。若转移矩阵可约（存在吸收态），长期分布依赖初始状态，结论完全不同。

## 第四步：结论表达

答题句式和数字要给全，避免「大约会趋于稳定」这类空话：

| 初始状态 | 5 步后处于状态 A 的概率 | 长期概率 π(A) | 收敛所需步数 |
| --- | --- | --- | --- |
| 状态 0 | 0.4521 | 0.3846 | 11 |
| 状态 1 | 0.3987 | 0.3846 | 8 |
| 状态 2 | 0.3312 | 0.3846 | 9 |

结论写法：*"在给定转移矩阵下，系统长期处于状态 A 的概率为 0.3846；从任一初始状态出发，约 8～11 步后进入稳态，误差小于 $10^{-3}$。"*

## 灵敏度：转移概率估错会怎样

把转移矩阵每一行扰动 $\pm 5\%$（重新归一化），观察 $\pi$ 的变化幅度：

```python
def perturb(P, eps=0.05, n=300, seed=7):
    rng = np.random.default_rng(seed)
    res = []
    for _ in range(n):
        Q = P * (1 + rng.uniform(-eps, eps, P.shape))
        Q = Q / Q.sum(axis=1, keepdims=True)
        res.append(stationary(Q))
    res = np.array(res)
    return res.mean(axis=0), res.std(axis=0)

mean_pi, sd_pi = perturb(P)
print("π 均值:", np.round(mean_pi, 4))
print("π 标准差:", np.round(sd_pi, 4))
```

若标准差相对均值超过 10%，说明数据量不足或状态划分过细，需要在论文里明确写为局限。

## 一句话总结

马尔可夫链类赛题拿分的不是「会不会求平稳分布」，而是**状态怎么划、参数怎么估、结论怎么写数字**。
