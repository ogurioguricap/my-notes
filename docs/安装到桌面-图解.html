📲 把「我的笔记」装成 App

装完后：桌面/主屏有图标、全屏打开没有地址栏、断网也能翻已看过的内容。而且以后改笔记不用重新安装，刷新就是最新。

最快的办法：在电脑上用 Chrome 或 Edge 打开 https://ogurioguricap.github.io/my-notes/， 然后点页面右上角的 📲 按钮 —— 能一键装就直接装上；不能的话会弹出对应的图文步骤。

Windows / Mac（Chrome · Edge）

🖥 桌面电脑

  1. 用 Chrome 或 Edge 打开本站必须是这两个浏览器；微信/QQ 内置浏览器不行。
  2. 看地址栏右侧有没有「安装」小图标一个显示器带向下箭头的图标，点它 → 「安装」。
  3. 找不到图标就进菜单找 Chrome：右上角 ⋮ → 「保存并分享」→「安装页面为应用」
    Edge：右上角 ⋯ → 「应用」→「将此站点作为应用安装」
  4. 确认桌面、开始菜单、任务栏都会出现「我的笔记」，图标是那张头像。
装好后是独立窗口：没有地址栏、没有标签页，和原生软件一样。

安卓手机（Chrome / Edge）

🤖 安卓

  1. 用 Chrome 打开本站Edge 也可以，步骤类似。
  2. 点右上角 ⋮ 菜单选择「安装应用」或「添加到主屏幕」。
  3. 确认主屏出现图标，点开全屏显示。
部分手机（小米/华为/OPPO）会直接弹「添加到桌面」的提示，点一下就行。

iPhone / iPad（Safari）

🍎 iOS

  1. 必须用 Safari 打开iOS 不支持一键安装，而且只有 Safari 能添加到主屏。如果在微信里，先点右上角 … → 「在 Safari 中打开」。
  2. 点屏幕底部的「分享」按钮方框带向上箭头那个图标。
  3. 往下滑，选「添加到主屏幕」然后点右上角「添加」。
  4. 完成主屏出现「我的笔记」，点开是全屏，和 App 一样。
iOS 的网页 App 有功能限制：不能后台同步、缓存容量较小。看笔记、编辑、标注、搜索都正常。

装成 App 之后有什么不一样

能力网页版装成 App 后
打开方式浏览器 + 地址栏桌面/主屏图标，独立窗口
断网使用需提前打开过已看过的内容都能翻
内容更新刷新即最新同样刷新即最新（不用重装）
可视化编辑 / 手写标注✅✅（手机上也一样）
能否上架应用商店—不能（需要另外打包，见「文档-做成App的三条路线.md」）
卸载很简单：Windows 在「设置 → 应用」里卸载，或右键桌面图标删除；安卓长按图标拖到「卸载」；iOS 长按图标 → 「移除 App」→「删除书签」。
卸载不会删除任何笔记——笔记都在你的 GitHub 仓库和本地项目里。
